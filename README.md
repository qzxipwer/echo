# Echo — клиент Яндекс Музыки (Android)

Kotlin + Jetpack Compose + Media3. Тёмная тема, мини-плеер, полноэкранный плеер,
фоновое воспроизведение с уведомлением. Токен хранится в EncryptedSharedPreferences.

Использует НЕОФИЦИАЛЬНЫЙ API Яндекс Музыки: нужна подписка Плюс, API может измениться.
Код не тестировался на устройстве.

## Как получить APK

### Вариант 1: GitHub Actions (без Android Studio)
1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта.
2. Откройте вкладку Actions → «Build APK» → Run workflow.
3. Через 5–10 минут скачайте артефакт `Echo-apk` и установите `app-debug.apk` на телефон.

### Вариант 2: Android Studio
Откройте папку проекта, дождитесь синхронизации Gradle, Build → Build APK(s).
